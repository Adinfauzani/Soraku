# AGENTS.md — Soraku Monorepo

## Stack (README is outdated)

- `apps/api` — NestJS + Prisma (PostgreSQL + Redis + Supabase + Firebase). `/api` global prefix.
- `apps/web` — Vite + React 19 + TanStack Router + Tailwind 4. Proxy `/api` → `localhost:4000`.
- `apps/admin` — Next.js 15.
- `apps/worker` — Cloudflare Worker (Hono + Wrangler).
- `apps/desktop` — Electron torrent client (depends on `packages/native`, `packages/torrent-client`).
- `apps/mobile` — Kotlin/Android + Jetpack Compose (Gradle, not pnpm).
- `apps/landing` — has `src/` but no `package.json`; cannot be built yet.
- `packages/native`, `packages/torrent-client` — desktop only. `packages/shared-types`, `packages/ui/*`, `packages/branding`, `packages/config` — shells/empty; don't import from them.

## Package manager

Use **pnpm** (`packageManager: pnpm@11.20.0`, `.npmrc` `legacy-peer-deps=true`). Ignore stale `bun.lock` and `package-lock.json`.

**No `turbo.json` at root.** Root `pnpm lint / build / test / dev` all fail ("Could not find turbo.json"). Run tasks inside each app dir, e.g. `cd apps/api && pnpm lint`.

## Per-app commands

`apps/api` (NestJS + Prisma):
- `pnpm prisma generate` — **MUST run before build/dev** (`@prisma/client` doesn't exist until then).
- `pnpm prisma migrate dev` — apply local migrations (`prisma/migrations/`).
- `pnpm run start:dev` — dev server (reads `env.PORT`; `.env` `PORT=4000`, schema default `3000`, `main.ts` fallback `3001` — verify the port you need).
- `pnpm build` — `nest build` → `dist/`.
- `pnpm lint` — `eslint 'src/**/*.ts' --fix`.
- `pnpm test` — `jest`; `pnpm test:e2e` — e2e jest config.
- Entry: `src/main.ts` (`setGlobalPrefix('api')`); serverless entry `src/serverless.ts` (Vercel).
- Env validated at startup via `@t3-oss/env-core` + Zod (`src/config/env.ts`). Required: `DATABASE_URL`, `SUPABASE_URL/KEYS`, `ANILIST_CLIENT_ID/SECRET`. Copy `apps/api/.env.example` → `apps/api/.env`. Firebase SA JSON via `FIREBASE_SERVICE_ACCOUNT_JSON` or `FIREBASE_SERVICE_ACCOUNT_PATH`.

`apps/web` (Vite + React):
- `pnpm dev` — Vite on :3000, proxies `/api` to :4000 (API must be running).
- `pnpm build` — `tsc -b && vite build`.
- `pnpm lint` — `eslint .`.
- `src/routeTree.gen.ts` is generated by TanStack Router plugin — don't hand-edit.
- Env: `VITE_API_BASE_URL` (copy `.env.example` → `.env` / `.env.local`; committed example has a stale prod URL).

`apps/admin` (Next.js): `pnpm dev` / `pnpm build` / `pnpm lint` (`next lint`) / `pnpm test` (jest).

`apps/desktop` (Electron): `pnpm dev` / `pnpm build` / `pnpm build:linux`. `build` = `electron-vite build`; typecheck split into `typecheck:node` / `typecheck:web`.

`apps/worker` (Cloudflare): `pnpm dev` (`wrangler dev`) / `pnpm deploy` / `pnpm deploy:staging` / `pnpm cf-typegen` (`wrangler types`). Keep `wrangler.toml` `ORIGIN_API_URL`/`ORIGIN_WEB_URL` in sync with deployed URLs.

`apps/mobile` (Gradle): `./gradlew assembleDebug` / `./gradlew assembleRelease`. Requires Android SDK (`local.properties`; `local.properties.example` committed). `google-services.json` is gitignored/not committed — don't commit real Firebase keys.

## Two Prisma schemas (do not confuse)

- `apps/api/prisma/schema.prisma` — main backend; anime keyed by `anilistId` (`AnimeMapping`).
- `apps/web/prisma/schema.prisma` — web direct DB access; local `anime.id` (cuid).

Different models and ID strategies. Verify which schema a change belongs to.

## Infra / deployment

- `infra/docker/docker-compose.yml` — API on :4000 + sidecars `wajik-api:3001` and `miruro-api:3002` (same compose network; use service names as host, not localhost).
- Vercel (`vercel.json`) — `buildCommand` jalan `cd apps/api && pnpm prisma generate && pnpm build`, lalu `builds` (`@vercel/node`) deploys `apps/api/dist/serverless.js` (JS sudah di-compile, bukan TS source). Pastikan `DATABASE_URL` di-set di Vercel Environment Variables (termasuk untuk Build).
- Worker: `wrangler deploy`; routes for `soraku.app/info/*`, `/watch/*`, `/stream/*`.

## Gotchas

- `pnpm install` at root installs workspace including `infra/*` (wajik-anime-api, miruro-api).
- `apps/api/.env`, `.env.local`, `*.env` are gitignored — create locally from `.env.example`.
- `apps/mobile/google-services.json` exists locally but is gitignored.
- Husky: `.husky/` only has `_/husky.sh`; activated by `pnpm prepare` (`husky install`).
- `.agents/AGENTS.md` is a stale Flutter/Next.js copy — this root file is authoritative.
